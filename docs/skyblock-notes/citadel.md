# Citadel of Golden Sands (Realm 4, issue #42)

GDD 3.1: "Des fleuves de poussière d'or coulent à l'envers. Le temps local est instable." Guardian: the Temporal Pharaoh.

- **Zone**: `sb_citadel`, built once by `island/CitadelRealm` from `CitadelPlan` (marker `island/citadel-build.json`, bump
  `CitadelPlan.VERSION` to rebuild). Main island of sand around a giant hourglass, six dune islets, four dust columns, the
  Pharaoh's stepped pyramid in the north. The Sky Gate lights for the players who fought the boss named by the setting
  `island.citadel.gate-boss` (the Mycelial Queen).
- **Time Tide** (`api/TimeTide`): calm 720 s, surge 240 s, stall 240 s (`island.citadel.tide.*`), computed from the clock only, so
  there is no state to save and every server agrees. In the Citadel: surge = Speed + Haste, stall = Slowness, an action bar
  shows the phase, and `citadel_tide:<phase>` quest events fire when it changes.
- **Chrono Sand**: local resource (`realm_resource` row, p0 0.06 / soft 12 / dur 36 like the others, to tune), also paid by the
  Pharaoh (2-4, +6 the first time). Forges the Chrono Module and the Sandglass.
- **Chrono Module** (`quarry/MachineModule.CHRONO`, "buffers temporels"): the Miner follows the tide (x1.5 in a surge, x0.6 in a
  stall). A Miner that cannot run (no Flux, full chest) banks half of the cycles it loses, a stalled tide banks what it costs;
  a running Miner in calm or surge pays back at most 1 extra cycle per second from the buffer (cap 120), with no extra Flux.
  Nothing is paid back during a stall. Numbers: `quarry.machines.module.chrono.*`. The buffer is `MachineData.buffer`.
- **Sandglass** ("recettes à durée"): right-click, consumed, the Forge job with the most time left loses half of what remains
  (`QuarryService.accelerate`). Forged from 2 Chrono Sand + glass + gold.
- **Temporal Pharaoh** (`boss.sql`, id `temporal_pharaoh`, husk, tier 3 like the other Guardians, weakness Frost, resists Ember):
  void rifts (`void_zones`), time skips (`teleport_behind`), mummies, a hourglass shield (`shield_crystals`) in the last phase.
  Key `pharaoh_scarab` (Citadel Bastion Key; forged at the Forge from Bronzite, gold and clocks), component `temporal_core` (hard pity), material `pharaoh_linen` (Resonance forge, Crucible).
- **Citadel Bastion**: `citadel_bastion`, palette `citadel`, Resonance row `temporal_pharaoh|citadel|pharaoh_linen|28`.
- **Quests**: category `citadel` (`citadel_01`..`citadel_08`), generated by `scripts/gen_quests.py`.
- **Economy**: Chrono Sand 60 and Pharaoh's Linen 40 at the adventurer, never traded on the market, two contracts
  (`c_chrono_sand`, `c_pharaoh`). No tide-driven price yet.
- **Sprites**: drawn by script (`art/quarry_items.py`, `art/boss_items.py`). An ElevenLabs concept sheet was generated but the
  download host is blocked from the dev sandbox, so it could not be imported: redo it through `art/import_textures.py` if wanted.
